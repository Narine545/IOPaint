# IOPaint — быстрый старт на Windows (сборка под CPU/AMD APU)

Этот форк собран под машины **без дискретной видеокарты NVIDIA** — например
AMD Ryzen 7 5700G + Radeon Vega (iGPU) + 16 ГБ RAM. Ставится одним кликом,
работает на CPU, при желании умеет задействовать iGPU через DirectML.

---

## 1. Установка (один раз)

Нужен только **Python 3.10–3.12** с сайта python.org
(при установке обязательно отметьте галочку **«Add python.exe to PATH»**).

```
git clone https://github.com/Narine545/IOPaint.git
cd IOPaint
IOPaint.bat
```

Если Git не установлен — скачайте ZIP кнопкой «Code → Download ZIP»,
распакуйте и запустите `IOPaint.bat` двойным кликом.

Первый запуск:

* создаёт изолированное окружение `.venv` внутри папки проекта
  (ничего не ломает в системном Python);
* ставит **CPU-версию PyTorch** (~250 МБ вместо ~2.5 ГБ с CUDA, которая вам
  всё равно бесполезна);
* ставит IOPaint + плагины удаления фона (`rembg`, `pymatting`);
* скачивает модели `lama` и `isnet-general-use`;
* открывает браузер на `http://127.0.0.1:8080`.

Дальше запускать — тем же `IOPaint.bat` (или `windows\start.bat`),
установка повторно не выполняется.

### Файлы в папке `windows\`

| Файл | Что делает |
|------|------------|
| `install.bat` | полная установка/переустановка окружения |
| `start.bat` | обычный запуск (CPU) |
| `start-directml.bat` | запуск с удалением фона на Radeon iGPU (эксперимент) |
| `install-diffusion.bat` | доустановить Stable Diffusion и т.п. (~3 ГБ) |
| `update.bat` | `git pull` + обновление пакета |
| `settings.cmd` | **все настройки запуска: порт, модели, потоки, папки** |

Менять параметры нужно именно в `settings.cmd` — остальные скрипты его читают.

## 2. Удаление фона: что выбрать

В меню плагинов (иконка кубиков слева сверху) у `RemoveBG` теперь три режима:

| Пункт меню | Что происходит | Скорость (12 Мп, 5700G) |
|---|---|---|
| **Remove Background** | «сырая» маска модели | ~1.5–3 с |
| **Remove Background (soft edges)** | + альфа-маттинг `fast` (guided filter) | +0.2–0.5 с |
| **Remove Background (hair / best quality)** | + альфа-маттинг `quality` (closed-form matting) | +2–6 с |

Плюс **Generate Mask** — вернуть маску вместо вырезанного объекта (удобно,
чтобы потом стереть фон ластиком или доработать кистью).

### Модели (меняются в Settings или в `settings.cmd`)

| Модель | Для чего |
|---|---|
| `isnet-general-use` | **реальные фото**, особенно на светлом/белом фоне — ваш основной вариант |
| `briaai/RMBG-1.4` | универсальная, часто лучше на сложном фоне; работает на CPU и CUDA |
| `birefnet-general` | максимальное качество, медленно и требует больше RAM |
| `u2net_human_seg` | только люди, быстрая |
| `silueta` / `u2netp` | самые быстрые, качество ниже |
| **AnimeSeg** (отдельный плагин) | **аниме-рисунки** — обучена именно на них, для рисовки почти всегда лучше, чем любая «фотографическая» модель |

Для аниме порядок такой: плагин **Anime Segmentation** → `soft edges`.
Для фото: **RemoveBG** + `isnet-general-use` → `soft edges`, а для волос/шерсти
на важных кадрах — `hair / best quality`.

### Почему пропал белый ореол

При вырезании объекта с белого фона в полупрозрачных пикселях остаётся
подмешанный белый цвет — на тёмной подложке это видно как светлая кайма.
Теперь по умолчанию включён **color spill removal**: решается уравнение
`I = α·F + (1−α)·B`, цвет фона оценивается по самому изображению, и из краевых
пикселей вычитается «бывший фон». Отключается флагом
`--no-remove-bg-remove-color-spill`.

## 3. Пакетная обработка из командной строки

```bat
.venv\Scripts\python -m iopaint remove-bg ^
    --image "C:\photos" ^
    --output "C:\cutouts" ^
    --model isnet-general-use ^
    --alpha-matting quality
```

Полезные флаги: `--anime` (модель для рисунков), `--save-mask` (сохранять
маски вместо вырезов), `--cpu-threads 8`, `--matting-max-size 1600`.

Стирание объектов по готовым маскам — прежняя команда:

```bat
.venv\Scripts\python -m iopaint run --model lama --device cpu ^
    --image "C:\in" --mask "C:\masks" --output "C:\out"
```

## 4. Настройка под ваше железо

`Ryzen 7 5700G` — 8 физических ядер / 16 потоков. IOPaint теперь сам
определяет **физические** ядра и ставит `torch.set_num_threads(8)`:
использовать все 16 потоков для свёрток медленнее, чем 8.

* `IOPAINT_CPU_THREADS=0` в `settings.cmd` — авто (рекомендуется).
  Если во время работы хотите нормально пользоваться ПК — поставьте `6`.
* 16 ГБ RAM: `lama` на изображении 12 Мп занимает ~2–3 ГБ, всё в порядке.
  Для 4K+ включите в UI `HD Strategy: Crop` (по умолчанию) — модель работает
  только вокруг маски, а не по всей картинке.
* `IOPAINT_MATTING_MAX_SIZE` — компромисс память/детализация для режима
  `quality`. 1280 безопасно, 1600–2000 даст чуть больше деталей на волосах.
* Модели лежат в `%USERPROFILE%\.cache\iopaint-models` — путь меняется в
  `settings.cmd` (удобно, если системный диск маленький).

### DirectML (Radeon Vega iGPU)

`windows\start-directml.bat` ставит `onnxruntime-directml` и запускает
удаление фона на встроенной графике. Честные ожидания:

* у iGPU всего 2 ГБ выделенной памяти и общая с CPU пропускная способность;
* выигрыш реален для ONNX-моделей (`isnet`, `u2net`, `silueta`) на картинках
  среднего размера — обычно в 1.5–2.5 раза;
* на больших изображениях возможен откат на CPU или ошибка нехватки памяти —
  тогда просто запускайте `start.bat`;
* `lama` (эразер) остаётся на CPU: torch-DirectML для неё нестабильна.

Всё это опционально, обычный `start.bat` работает всегда.

## 5. Если что-то пошло не так

| Симптом | Решение |
|---|---|
| `Python was not found` | поставить Python 3.12 и отметить «Add to PATH» |
| Долгий первый запуск | скачиваются модели (сотни МБ), дальше локально |
| `pymatting` не найден | `windows\update.bat` или `pip install pymatting` |
| Порт занят | поменять `IOPAINT_PORT` в `settings.cmd` |
| Хочу всё переустановить | удалить папку `.venv` и запустить `IOPaint.bat` |

Диагностика окружения: `.venv\Scripts\python -m iopaint start --help`,
в логе при старте печатаются версии пакетов и строка `Acceleration: ...`
с числом физических ядер и доступностью DirectML.
